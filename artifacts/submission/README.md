# Insider Trading Detection on Polymarket

## Objective

Investigate potential informed or insider trading activity on Polymarket between November 1, 2025 and May 1, 2026.

This repository contains:

- Data collection pipeline
- Market selection methodology
- Public event verification
- Wallet feature engineering
- Insider likelihood ranking
- Investigation artifacts

## Repository Structure

src/
    collectors/
    normalizers/
    analysis/

sql/

artifacts/submission/
    csv/
    report/

## Running

1. Collect markets
2. Normalize markets
3. Select investigation universe
4. Collect trades
5. Verify public events
6. Build wallet features
7. Generate wallet ranking
